# ESX Data Manager

Manage player data efficiently with ESX Legacy Framework

## Features

- Player data management with ESX Legacy Framework
- Database operations for storing and retrieving player data

## Requirements

- FiveM server
- ESX Legacy Framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start esx-data-manager` to your server.cfg file

## Usage

### Commands

- `/fivemscript` - Example command to trigger server events

### Events

- `fivemscript:clientEvent` - Client-side event
- `fivemscript:serverEvent` - Server-side event

### Callbacks

- `fivemscript:getData` - Callback to retrieve player data

## Configuration

Edit the `config.lua` file to configure database settings and script options.
